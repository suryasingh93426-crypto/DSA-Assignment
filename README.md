## 1. Stack Using Array

Operations implemented:

- PUSH
- POP
- PEEK
- DISPLAY

The program also handles:

- Stack Overflow
- Stack Underflow

### Time Complexity

| Operation | Complexity |
|---|---|
| PUSH | O(1) |
| POP | O(1) |
| PEEK | O(1) |
| DISPLAY | O(n) |

### Space Complexity

O(n)

## 2. Circular Queue Using Array

Operations implemented:

- ENQUEUE
- DEQUEUE
- FRONT
- DISPLAY

The circular queue correctly handles:

- Queue Overflow
- Queue Underflow
- Reuse of empty positions

### Time Complexity

| Operation | Complexity |
|---|---|
| ENQUEUE | O(1) |
| DEQUEUE | O(1) |
| FRONT | O(1) |
| DISPLAY | O(n) |

### Space Complexity

O(n)
